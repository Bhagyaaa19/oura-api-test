Privacy Policy

Last updated: November 2026

Oura API Development Test is a non-commercial application used to test Oura API integration.

Data Collection

The application accesses data from the developer's own Oura account through authorized OAuth2 access.

Purpose

Retrieved data is used for testing API functionality and data preprocessing.

Data Storage

Retrieved data is stored in a protected development environment and is not published on this website.

Access and Revocation

Oura authorization can be revoked through the user's Oura account settings.

Contact

For questions about this application, contact the application developer using the contact details provided with the application registration.
